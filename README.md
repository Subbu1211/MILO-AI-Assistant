# 🤖 MILO — AI Voice & Text Assistant

MILO is a Python-based personal assistant designed to understand text and voice commands and help users perform useful tasks through a simple interface.

## ✨ Current Features

- 💬 Text command interface
- 🧠 Command processing foundation
- 👋 Interactive assistant responses
- 🚪 Graceful exit handling

## 🚀 Planned Features

- 🎙️ Voice input
- 🔊 Text-to-speech responses
- 🤖 AI/LLM integration
- 🌐 Browser automation
- 🖥️ Desktop automation
- ☁️ AWS integration
- 📝 Command history and logging

## 🛠️ Tech Stack

- Python
- Artificial Intelligence / LLMs
- Speech Recognition
- Desktop Automation
- AWS

## 📌 Project Status

🚧 **Under active development**

MILO is being rebuilt from the ground up with a modular architecture.
